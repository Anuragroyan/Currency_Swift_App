💱 Currency Converter App

Currency Converter App is a simple application that demonstrates currency conversion using real exchange-rate values stored as hardcoded rates for top countries. Users can enter an amount, select the currencies, and quickly view the converted value based on the available exchange rates.

✨ Features

* 💱 Currency conversion
* 🌍 Support for top-country currencies
* 💰 Enter custom amount
* 🔄 Select source and target currencies
* ⚡ Quick conversion results
* 📊 Rate-based calculations
* 📱 Simple and user-friendly interface
* 💾 Hardcoded exchange-rate data

🔄 Application Process

Open App → Enter Amount → Select Source Currency → Select Target Currency → Retrieve Rate → Calculate Conversion → Display Converted Amount

💰 Currency Conversion Flow

The user enters the amount they want to convert and selects the source and target currencies. The application retrieves the corresponding hardcoded exchange rate, performs the conversion calculation, and displays the converted amount.

Amount + Source Currency + Target Currency → Exchange Rate → Conversion Calculation → Result

📊 Exchange Rate Handling

The application uses predefined exchange-rate data for selected top-country currencies. These rates are used to demonstrate how currency conversion works without requiring a live exchange-rate API or external backend.

🎯 Project Purpose

The project demonstrates the basic implementation of a currency conversion system, focusing on user input, currency selection, exchange-rate handling, calculation logic, and displaying quick conversion results.
